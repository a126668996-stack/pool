# 夜場撞球

3D 撞球網頁遊戲：8 號球、9 號球、開侖、自由練習。可加塞、跳球、扎桿，支援同一台輪流打和兩人連線對戰（PeerJS 點對點，不用註冊）。

**提示線與推薦路線**：右側「提示」打開後，會用遊戲本身的物理預先跑一次這桿，畫出母球和被碰到的球會怎麼走、停在哪，並顯示這桿會不會得分或過關。「推薦」會自動找出這個球形最穩、走位最好的打法（薄削、跟球、拉球、翻庫），幫你把瞄準和擊球點設好，力道條上會標出建議的力道。自由練習預設開啟，其他單機模式可自己切換，連線對戰不開放。

打開 `index.html` 就能玩，整個遊戲只有這一個檔案。
